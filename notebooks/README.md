# Notebooks

This directory is reserved for exploratory analysis (e.g. inspecting
retrieval failures, plotting per-item metrics from `experiments/results/`,
or prototyping new chunking/reranking strategies). No notebooks were needed
to produce the results in `RESULTS.md` - all reported numbers come from the
command-line evaluation scripts (`backend.evaluation.baselines` /
`.ablation`), which are reproducible without a notebook.
